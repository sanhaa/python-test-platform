# 2026-AI-PD 실습 기초 — 사전 테스트 플랫폼

교육 입과자의 파이썬 기초 수준을 파악하기 위한 사전 테스트 웹 플랫폼입니다.
객관식 7문항 + 주관식(빈칸 채우기) 3문항, 문항당 10점 / **100점 만점**.

## 실행

```bash
pip install -r requirements.txt
python app.py
```

기본 주소는 `http://0.0.0.0:5000` 입니다.
교육생은 같은 네트워크에서 **강사 PC의 IP**로 접속합니다. (예: `http://192.168.0.10:5000`)

```bash
hostname -I          # 리눅스/WSL에서 내 IP 확인
ipconfig             # 윈도우
```

포트를 바꾸려면 `PORT=8080 python app.py`.

> WSL에서 실행하고 외부 PC가 접속해야 한다면 윈도우 방화벽/포트 포워딩(`netsh interface portproxy`) 설정이 필요할 수 있습니다. 강사 PC에서 직접 윈도우 파이썬으로 실행하는 편이 간단합니다.

## 교육생 사용 흐름

1. 첫 화면에서 **Knox ID 입력** → 시작하기 (별도 인증 없음)
2. 문제 1 → 2 → … 순서대로 진행. 왼쪽 사이드바에서 원하는 문항으로 **바로 점프** 가능
3. 답을 고르거나 입력하면 **자동 저장**됩니다 (사이드바 번호가 초록색으로 바뀜)
4. **10문항 전부** 답해야 제출 버튼이 활성화됩니다
5. 제출 후에는 답안 수정 불가. 전체 문제와 본인 답안을 다시 조회할 수 있습니다

Knox ID는 대소문자를 구분하지 않으며 공백은 제거됩니다. 같은 Knox ID는 같은 사람으로 취급됩니다.

## 관리자 사용 흐름

첫 화면 Knox ID 칸에 **`admin-123456`** 을 입력하면 관리자 페이지로 들어갑니다.

관리자 페이지에서 확인·조작할 수 있는 것:

- 응시자 수 / 제출 완료 수 / 진행 중 / 평균 점수
- 응시자별 **점수(100점 환산)** 와 **문항별 O·X 표**
- 문항별 정답률 — 어느 개념에서 많이 막혔는지 파악용
- Knox ID 클릭 → 응시자별 상세 (문제·응시자 답·정답 비교)
- **초기화**: 답안·제출 상태를 지워 다시 응시하게 함 (제출 후 수정은 이 방법으로만 가능)
- **삭제**: 응시자 기록 완전 삭제
- **전체 답안 초기화**: 모든 응시자의 답안을 한 번에 지움 (Knox ID 명단은 유지)
- **전체 기록 삭제**: 명단까지 통째로 비움 — 새 기수 교육 시작용
  - 두 전체 작업은 실행 직전 상태를 `data/backup-날짜-시각.json` 으로 자동 백업합니다
- **CSV 내려받기**: 엑셀에서 바로 열리는 결과표

### 주관식 수동 채점

주관식 3문항은 자동 채점됩니다. 공백·대소문자·따옴표·괄호·마침표·밑줄을 무시하므로
`join`, `JOIN`, `.join()`, `" join "` 은 모두 정답 처리됩니다.

자동 채점이 애매한 답이 나오면 응시자 상세 페이지에서 문항별로
**정답 처리 / 오답 처리 / 자동 채점으로** 버튼을 눌러 바꿀 수 있습니다.
수동 채점한 문항은 현황표에 `*` 로 표시됩니다.

## 정답 키

| 문항 | 주제 | 정답 |
|---|---|---|
| 1 | 딕셔너리 `.get()` 기본값 | 3번 — 제주의 날씨 데이터를 찾을 수 없습니다. |
| 2 | 문자열 슬라이싱 | 1번 — `ABC DEF IJ` |
| 3 | 중첩 반복문 | 4번 — 10번 |
| 4 | 조건부 표현식 | 1번 — `ko` |
| 5 | 중첩 JSON 접근 | 2번 — `recv_json['choices'][0]['message']['content']` |
| 6 | `range()` 세 번째 인자 | 1번 — 3줄 |
| 7 | 딕셔너리 초기화·리스트 누적 | 1번 — `1 user` |
| 8 | f-string | `f` |
| 9 | 공백 정리 | `join` |
| 10 | LangGraph 그래프 컴파일 | `compile` |

## 파일 구조

```
app.py                    Flask 라우트 · 채점 로직
questions.py              문제 은행 · 정답 · 답안 정규화
storage.py                JSON 파일 저장소 (락 + 원자적 쓰기)
templates/
  base.html               공통 레이아웃
  login.html              Knox ID 입력 화면
  exam.html               응시 화면 (사이드바 · 자동 저장)
  result.html             제출 후 조회 화면
  admin.html              관리자 현황판
  admin_student.html      응시자 상세 · 수동 채점
static/style.css
data/submissions.json     응시 기록 (자동 생성)
```

## 설정

`app.py` 상단에서 바꿀 수 있습니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `ADMIN_NAME` | `admin-123456` | 관리자 진입용 Knox ID |
| `SHOW_ANSWERS_TO_STUDENT` | `True` | 교육생 결과 화면에 점수와 정답을 함께 표시. `False` 로 바꾸면 본인 답안만 보임 |

세션 키는 환경변수 `TEST_PLATFORM_SECRET` 로 덮어쓸 수 있습니다.

문제를 고치거나 추가하려면 `questions.py` 의 `QUESTIONS` 리스트만 수정하면 됩니다.
문항 수를 바꾸면 총점(문항 수 × 10점)도 자동으로 따라갑니다.

## 백업

응시 기록은 `data/submissions.json` 파일 하나에 들어 있습니다.
교육이 끝나면 이 파일이나 CSV를 따로 보관하세요.

관리자 페이지의 전체 초기화·삭제를 실행하면 직전 상태가
`data/backup-날짜-시각.json` 으로 자동 백업됩니다. 되돌리려면 서버를 멈추고
그 백업 파일을 `submissions.json` 으로 덮어쓰면 됩니다.

`data/` 폴더는 gitignore 되어 있어 커밋되지 않습니다.

## 알아둘 점

- 교육생 인증 절차가 없습니다. Knox ID만 입력하면 누구나 접속합니다 (요구사항대로). 실제 Knox 계정과 대조하지 않습니다.
- Flask 개발 서버로 동작합니다. 사내 교육장 30~40명 규모에는 충분하지만, 공개 인터넷에 노출하는 용도는 아닙니다.
- 미제출 상태에서 같은 Knox ID로 다시 접속하면 답안이 초기화되고 처음부터 시작합니다.
  이미 제출한 Knox ID로 접속하면 제출 기록이 보호되어 결과 조회 화면으로 이동합니다.
